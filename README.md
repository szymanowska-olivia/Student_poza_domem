# Student_poza_domem
.NET Text Adventure Game where you become a newly arrived student. You stand before your dormitory wondering whether to go in when 3 fascinating persons come up to you, choose one main quest to complete through the game...

# About the game

It's designed to be kind of like a text labyrinth game where you decide where to go and what to do by writing commands in the terminal. Student poza domem focuses mostly on mechanics and serves as a learning project for OOP in C#. There's quests, dialouges and some plot (tho it's not really deep). The player can encounter enemies, interact with objects while completing their main objective assigned at the very begining.
